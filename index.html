(A Study on the Non-Linear Dynamic Shocks and Transmission Mechanisms of Global AI Capital Expenditures on Taiwan's ICT and Video Products Exports)
題目二（產業結構與總體經濟轉型導向）
《AI 浪潮下台灣電子零組件出口之結構轉型與總體經濟外溢效果分析》
(Structural Transformation and Macroeconomic Spillover Effects of Taiwan's Electronic Component Exports under the AI Boom)

二、 研究假說 (Hypothesis) 與經濟學理傳導機制

以題目一為例，其研究假說與傳導機制設計如下：

1. 研究假說

  • 主假說 (H1)：全球大型科技企業（如美系雲端服務商 Hyperscalers）的 AI 資本支出擴張，對台灣「資通與視訊產品」及「電子零組件」出口具有顯著的正向衝擊，且該傳導效果呈現顯著的時間遞延 (Time Lag) 與總體經濟乘數效應。
  • 虛無假說 (H0)：全球 AI 資本支出對台灣高科技出口無顯著因果關係。

2. 經濟學理傳導機制

  • 需求端 (Demand-pull Effect)：全球生成式 AI 爆發帶動算力需求，美系與跨國科技巨頭增加資料中心與伺服器資本支出。
  • 供應鏈鏈結 (Global Value Chain, GVC)：台灣位居全球半導體與高階伺服器代工的核心樞紐。國際 AI 終端需求透過跨國供應鏈傳導，直接拉動台灣的「電子零組件」（如晶圓代工、IC 設計）與「資通與視訊產品」（如 AI 伺服器、網通設備）出口。
  • 總體乘數效應 (Macroeconomic Multiplier)：出口擴張帶動國內民間投資、產業關聯效果與就業，進而推升整體經濟成長動能。

四、 Python 資料清洗與時間序列分析程式碼草稿

台灣 AREMOS 匯出的 CSV 檔案通常含有中文標頭與前置詮釋行。以下為標準的 Python 程式碼草稿：

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
import statsmodels.api as sm

# 1. 讀取 AREMOS 匯出的 CSV 檔案
# 假設檔案路徑為 'aremos_export.csv'，略過前幾行說明文字
df = pd.read_csv("aremos_export.csv", encoding="utf-8", skiprows=2)

# 顯示前幾行確認欄位名稱
print("原始資料預覽：")
display(df.head())

# 2. 資料清洗與前處理
df = df.rename(columns={df.columns[0]: "Time", df.columns[1]: "ICT_Export"})
df["Time"] = pd.to_datetime(df["Time"], errors="coerce")
df = df.dropna(subset=["Time"]).set_index("Time")

df["ICT_Export"] = pd.to_numeric(df["ICT_Export"], errors="coerce")
df = df.dropna()

# 3. 計算年增率 (YoY, Year-over-Year Growth Rate)
df["ICT_Export_YoY"] = df["ICT_Export"].pct_change(periods=12) * 100
df = df.dropna()

# 4. 基礎時間序列視覺化
plt.figure(figsize=(10, 5))
plt.plot(df.index, df["ICT_Export_YoY"], label="ICT & Video Products Export YoY (%)", color="b")
plt.axhline(0, color="red", linestyle="--", linewidth=1)
plt.title("Taiwan ICT Export YoY Growth Rate (AREMOS Data)")
plt.xlabel("Year")
plt.ylabel("YoY (%)")
plt.legend()
plt.grid(True)
plt.show()

# 5. 簡單自我迴歸分析 (AR Model) 示範
df["ICT_Export_YoY_Lag1"] = df["ICT_Export_YoY"].shift(1)
regression_data = df.dropna()

X = sm.add_constant(regression_data["ICT_Export_YoY_Lag1"])
y = regression_data["ICT_Export_YoY"]

model = sm.OLS(y, X).fit()
print(model.summary())
